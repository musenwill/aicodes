# calc24

24 点游戏求解器。输入 4 个 1-13 的整数，输出所有不重复、括号最少的算式。

## 使用方法

```bash
make                      # 编译
./calc24 1 2 3 4          # 求解
make test                 # 跑全部单元测试
./calc24 -V               # 查看版本信息
./calc24 -h               # 查看帮助
```

## 实现原理

实现分为两大部分：**寻找所有解**，和**对解进行去重与括号简化**。

---

## 一、寻找所有解

### 1.1 5 种算式形状

4 个数字和 3 个运算符可以构成 5 种不同的二叉树形状（Catalan 数 C₃ = 5）：

```
模板 1 (左结合)        模板 2 (平衡)         模板 3 (混合左)       模板 4 (混合右)       模板 5 (右结合)
  ((a⊕b)⊕c)⊕d           (a⊕b)⊕(c⊕d)        (a⊕(b⊕c))⊕d          a⊕((b⊕c)⊕d)          a⊕(b⊕(c⊕d))

      ⊕                      ⊕                    ⊕                    ⊕                      ⊕
     / \                    / \                  / \                  / \                    / \
    ⊕   d                  ⊕   ⊕                ⊕   d                a   ⊕                  a   ⊕
   / \                    / \ / \              / \                      / \                    / \
  ⊕   c                  a  b c  d            ⊕   c                    ⊕   d                  b   ⊕
 / \                                          / \                      / \                        / \
a   b                                        a   ⊕                    b   c                      c   d
                                                 / \
                                                b   c
```

其中 ⊕ 代表 `+` `-` `*` `/` 之一，a b c d 填入数字。

### 1.2 穷举搜索

对所有可能组合进行评估：

```
搜索空间 = 排列数 × 运算符组合数 × 模板数
         = P(4个数) × 4³ × 5
         ≤ 4! × 64 × 5 = 24 × 64 × 5 = 7680
```

实际排列数取决于重复数字（如 `3 3 8 8` 只有 6 种唯一排列）。

**排列生成**：回溯 + 按值去重（同一位不放入相同数字），生成无重复排列。

**运算符组合**：回溯生成 64 种（4³）。

**评估**：每个表达式用 `float64` 计算，误差在 `|result - 24| < 0.001` 内即认为等于 24。

```
for each 排列 of 4 个数字:
    a, b, c, d := 填入数字
    for each 运算符组合 (op1, op2, op3):
        for each 模板 tmpl:
            expr := tmpl(a, b, c, d, op1, op2, op3)
            if |expr.Eval() - 24| < 0.001:
                收集 expr
```

## 二、去重与括号简化

收集到的所有解中，存在大量等价重复。归一化管线对每个解依次应用以下变换，最终以唯一字符串作为去重键。

### 2.1 归一化管线总览

```
表达式 tree
  ↓
① 运算符推入（- 和 / 的互逆展开）
  ↓
② 加减链压平（+/- 混合链 → 正项 + 负项，排序）
  ↓
③ 乘除链压平（*/ 混合链 → 分子 + 分母，排序）
  ↓
④ toString（含运算符优先级括号最小化）
  ↓
归一化字符串 → 去重 map key
```

### 2.2 运算符推入（互逆展开）

将嵌套的逆运算符「推入」子树，消除 `-` 和 `/` 的右嵌套：

```
规则 1:  a - (b + c)  →  (a - b) - c      (减号对加法分配)
规则 2:  a - (b - c)  →  (a - b) + c      (减负得正)
规则 3:  a / (b * c)  →  (a / b) / c      (除号对乘法分配)
规则 4:  a / (b / c)  →  (a / b) * c      (除倒数得乘)
```

示例：
```
6 * 6 - (6 + 6)
  → 规则1: (6 * 6 - 6) - 6
  → toString: "6 * 6 - 6 - 6"          ← 少一对括号
```

### 2.3 加减链压平

混合 `+`/`-` 链中，减法视为加负数后正负项各自可重排。压平为「正项 `+` 正项 `-` 负项」规范形式：

```
算法 flattenAddSub:

  expr 是 + 节点:  正项=左正+右正,  负项=左负+右负
  expr 是 - 节点:  正项=左正+右负,  负项=左负+右正  (右侧「取反」)
  expr 是其他节点:  返回 ([expr], [])

压平后正负项各自排序，重建为左结合树。
```

示例：
```
11 * 4 - 11 - 9          → 正项 [11*4], 负项 [11, 9]  → 排序 → "11 * 4 - 9 - 11"
11 * 4 - 9 - 11          → 正项 [11*4], 负项 [9, 11]  → 排序 → "11 * 4 - 9 - 11"
                                                               ↑ 相同，去重 ✓
```

### 2.4 乘除链压平

与加减链对称。混合 `*`/`/` 链中，`/x` 等价于 `*(1/x)`，将操作数按分子/分母分类：

```
算法 flattenMultDiv:

  expr 是 * 节点:  分子=左分+右分,  分母=左母+右母
  expr 是 / 节点:  分子=左分+右母,  分母=左母+右分  (右侧「取倒」)
  expr 是其他节点:  返回 ([expr], [])

压平后分子分母各自排序，重建为「分子们 * ... / 分母们 / ...」。
```

示例：
```
2 * 3 / 1 * 4            → 分子 [2,3,4], 分母 [1]  → 排序 → "2 * 3 * 4 / 1"
2 / 1 * 3 * 4            → 分子 [2,3,4], 分母 [1]  → 排序 → "2 * 3 * 4 / 1"
                                                              ↑ 相同，去重 ✓
```

### 2.5 括号最小化（toString）

`toString(parentPrec)` 方法实现了**给定 AST 下的括号最小化**——只在运算符优先级要求时才加括号。

```
优先级:  + - 为 1,   * / 为 2

规则：当前节点优先级 < 父节点优先级 → 加括号
例外：对于 - 和 / 的右子节点，使用 parentPrec+1（防止 a-(b-c) 变为 a-b-c）
```

示例——左结合 `+` 链天然零括号：
```
AST:  ((1 + 2) + 3) + 4
      +              prec 1, parent=0 → 不加
     / \
    +   4            prec 1, parent=1 → 不加
   / \
  +   3              prec 1, parent=1 → 不加
 / \
1   2

→ toString: "1 + 2 + 3 + 4"      零括号 ✓
```

示例——混合优先级必须加括号：
```
AST:  (1 + 2) * 3
      *              prec 2, parent=0 → 不加
     / \
    +   3            prec 1, parent=2, 2>1 → 加括号
   / \
  1   2

→ toString: "(1 + 2) * 3"        必要括号 ✓
```

### 2.6 去重汇总

等价类去重的完整覆盖范围：

| 等价类型 | 变换 | 处理方式 |
|---------|------|---------|
| 交换律 | `a+b ↔ b+a`, `a*b ↔ b*a` | 压平排序 |
| 结合律 | `(a+b)+c ↔ a+(b+c)` | 压平为左结合 |
| 加减互逆 | `a-(b+c) ↔ a-b-c` | 运算符推入 + 压平 |
| 乘除互逆 | `a/(b/c) ↔ a/b*c` | 运算符推入 + 压平 |
| 负项交换 | `a-b-c ↔ a-c-b` | 加减链压平排序 |
| 分母交换 | `a/b/c ↔ a/c/b` | 乘除链压平排序 |
